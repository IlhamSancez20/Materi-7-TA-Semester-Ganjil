## 📌 1. Alasan & Tujuan Pembuatan / Why It Was Created

### 🇮🇩 Bahasa Indonesia (Primer)
Presentasi web interaktif berbasis **Single Page Application (SPA)** ini dirancang dan dibuat khusus untuk mendukung **Tugas Akhir Semester Ganjil Kelas 7 Informatika**. 

**Latar Belakang & Motivasi:**
1. **Mengubah Paradigma Presentasi Pasif:** Slide presentasi konvensional (seperti PowerPoint statis) sering kali membosankan bagi siswa Kelas 7. Media ini menggabungkan visualisasi cyberpunk yang futuristik, simulasi nyata, dan gamifikasi.
2. **Praktik Simulasi Langsung (Hands-on Learning):** Memberikan pemahaman nyata mengenai cara membagikan tautan dokumen digital (Canva & Google Slides) secara aman dan tepat akses (*Viewer*, *Commenter*, *Editor*).
3. **Penyedia Tool Acak Presentasi (Randomizer):** Mempermudah guru dan siswa dalam menentukan urutan tampil kelompok serta jadwal presentasi secara adil, transparan, dan dapat diekspor langsung ke WhatsApp atau file teks.
4. **Gamifikasi Edukasi Komputasi:** Menyediakan 10 mini-game bertema IT yang mengasah logika, pemecahan masalah (*computational thinking*), serta refleks penggunaan keyboard.

---

### 🇬🇧 English (Secondary)
<details>
<summary><b>Click to read in English</b></summary>

This interactive web presentation based on **Single Page Application (SPA)** architecture was specially designed and built to support the **Grade 7 Informatics First Semester Final Project**.

**Background & Purpose:**
1. **Transforming Passive Presentation Paradigms:** Conventional presentation slides (such as static PowerPoint) are often disengaging for Grade 7 students. This platform combines futuristic cyberpunk visuals, real-world simulations, and gamification.
2. **Hands-on Simulation Learning:** Providing practical understanding of how to share digital document links safely and assign proper permissions (*Viewer*, *Commenter*, *Editor*) on Canva & Google Slides.
3. **Integrated Presentation Schedule Randomizer:** Assisting teachers and students in fairly and transparently randomizing group presentation order and time slots, with direct export features for WhatsApp and text files.
4. **Computer Science Gamification:** Offering 10 IT-themed mini-games designed to enhance logic, computational thinking, and keyboard reflexes.
</details>

## 📑 2. Isi & Fitur Utama / Contents & Features

Aplikasi ini terdiri dari **12 Modul Slide Interaktif** yang terstruktur:

| Slide | Modul / Topic | Deskripsi Fitur Interaktif |
| :---: | :--- | :--- |
| **01** | 🎲 **Randomizer Tool** | Pengacak 8 urutan kelompok + slot tanggal & waktu tampil secara simultan. *Export to WhatsApp & TXT*. |
| **02** | 💻 **Simulasi Editor Canva & Slides** | Simulasi interaktif pengubahan akses publik (*Anyone with the link*) & peran pengakses di Canva & Google Slides. Fitur tes mode Incognito. |
| **03** | 🔍 **Deep-Dive Permissions** | Edukasi peran pengguna (*Viewer*, *Commenter*, *Editor*) dilengkapi dengan *Checklist Kesiapan Link*. |
| **04** | 🚀 **Cover Presentasi** | Tampilan utama bertema Cyberpunk Glow dengan navigasi cepat. |
| **05** | 👥 **Anggota Kelompok** | Kartu profil 3D interaktif 5 anggota kelompok beserta statistik kopi, bug level, dan quote favorit. |
| **06** | ⏳ **Sejarah & Evolusi Informatika** | *Timeline* interaktif dari masa Ada Lovelace (1800-an), ENIAC, World Wide Web, hingga Generative AI. |
| **07** | ⚡ **Fungsi Utama Informatika** | 4 Pilar Komputasi: *Input/Capture*, *Processing*, *Storage*, dan *Output/Display*. |
| **08** | 🌐 **Manfaat Informatika Nyata** | Infografis interaktif sektor Kesehatan (*Telemedicine*), Pendidikan (*E-Learning*), dan Ekonomi (*E-Commerce*). Fitur *Boost Metric*. |
| **09** | 💻 **Simulator Koding** | Editor JavaScript interaktif di browser (*Playground*) untuk menguji logika algoritma sederhana & preset program. |
| **10** | 🎮 **10 Mini-Games IT & Keyboard HUD** | Koleksi 10 game IT berbasis keyboard fizik & layar sentuh (Detail di bawah). |
| **11** | 📊 **Dashboard Kesimpulan** | Rangkuman 4 poin kunci pembelajaran dan indikator status pemahaman materi 100%. |
| **12** | 🎉 **Penutup & Komunitas WA** | Selebrasi kembang api, rating interaktif 5-bintang, kontak WhatsApp, serta tautan grup Kelas 7A - 7G. |

---

### 🎮 Rincian 10 Mini-Games IT (Slide 10)

<details open>
<summary><b>Klik untuk melihat daftar 10 Mini-Game IT</b></summary>

1. 🧩 **Puzzle Meme Informatika:** Menyusun potongan gambar meme koding (*Auto-solve available*).
2. 🐛 **Whack-a-Bug:** Membasmi bug kodingan biasa (+10) dan Golden Bug (+20).
3. 🃏 **Memory Card 3D:** Mencocokkan 6 pasang kartu ikon IT identik dengan efek flip 3D.
4. ❓ **Kuis Tebak Error & Syntax:** 5 Pertanyaan seputar HTTP 404, SyntaxError, dan CSS dengan *Hotkey* [A, B, C, D / 1, 2, 3, 4].
5. 🔐 **Validator Password Absurd:** Pengujian syarat password unik secara *real-time*.
6. 💥 **Stress Release Dev Clicker:** Menuntaskan *project client* dengan menekan `SPACE`/`ENTER` atau klik secepatnya.
7. ☕ **Tangkap Kopi Programmer:** Menangkap cangkir kopi falling item menggunakan tombol panah `←` `→` / `A` `D`.
8. 🔌 **Colok Kabel Server LAN:** Menyambungkan 3 kabel server ke port router yang sesuai (`1,2,3` & `Q,W,E`).
9. 🦖 **Bug Runner Dino Jump:** Game lompat rintangan bug koding berbasis HTML5 Canvas (`SPACEBAR` / `UP ARROW`).
10. 🎰 **Roda Nasib Koding:** Spin wheel ramalan nasib koding harian berbasis HTML5 Canvas.

</details>

## ⌨️ 3. Panduan Interaktif & Shortcut Keyboard

Aplikasi ini mendukung kontrol navigasi via keyboard serta fitur khusus proyektor / papan tulis:

| Key / Shortcut | Fungsi / Action |
| :---: | :--- |
| <kbd>P</kbd> | **Toggle Mode Proyektor (Papan Tulis):** Mengubah tema dari Cyber Dark ke Mode Terang Kontras Tinggi (*High-contrast Light Mode*) cocok untuk Infocus/Proyektor. |
| <kbd>→</kbd> / <kbd>Space</kbd> | Pindah ke Slide Selanjutnya (*Next Slide*). |
| <kbd>←</kbd> | Pindah ke Slide Sebelumnya (*Prev Slide*). |
| <kbd>A</kbd> / <kbd>D</kbd> atau <kbd>←</kbd> / <kbd>→</kbd> | Kontrol Kiri/Kanan pada Mini-Game Tangkap Kopi. |
| <kbd>SPACEBAR</kbd> / <kbd>↑</kbd> | Kontrol Lompat pada Bug Runner Dino Jump. |
| <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> & <kbd>Q</kbd> <kbd>W</kbd> <kbd>E</kbd> | Hotkey Memilih Kabel & Port pada Game Colok LAN Server. |
