Modul 03 • Deep-Dive Permissions

Pengaturan Peran Pengguna Google Slides

Pahami perbedaan antara Viewer, Commenter, dan Editor agar file presentasimu tetap aman!

1. Pengakses Lihat (Viewer)

Pengunjung hanya bisa **melihat slide** tanpa bisa mengubah tulisan atau menghapus gambar. Cocok untuk dikirim ke audiens umum atau guru saat penilaian.

Paling Aman 🔒

2. Pengomentar (Commenter)

Pengunjung bisa melihat slide DAN meninggalkan **catatan revisi** di samping slide. Sangat bagus untuk sesi konsultasi materi dengan kelompok lain.

Untuk Review 💬

3. Editor (Full Control)

Pengunjung bisa **mengubah seluruh isi slide**, menambah teks, atau menghapus halaman. HANYA berikan akses ini kepada teman satu kelompokmu!

Modul 07 • Fungsi Utama

Fungsi Utama Informatika dalam Sistem

4 Pilar fungsional pengolahan data menjadi informasi yang berguna bagi kehidupan.

1. Input & Capture

Menangkap data mentah dari keyboard, sensor IoT, kamera, atau barcode scanner.

2. Processing

Mengolah data mentah menggunakan logika matematika & algoritma terstruktur.

3. Storage

Menyimpan data secara permanen di Database atau Cloud Storage agar aman.

4. Output & Display

Menampilkan hasil olahan dalam bentuk Grafik Dashboard, Laporan, atau Visual UI.
